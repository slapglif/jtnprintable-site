# JTN Printable — 10-post Pinterest organic queue

**Purpose:** send qualified Pinterest traffic to useful owned-site guides, then to the matching Etsy listing. Every destination below is a live JTN Printable guide and the tracking URL identifies Pinterest organic traffic without treating it as Etsy traffic.

## Publishing rules

- Publish only from the owned `JTNPrintableCo` Pinterest profile.
- Use the exact artwork/product mockup associated with the destination. Do not use invented rooms, fabricated reviews, price claims, or deceptive before/after images.
- Link each Pin to the **owned-site tracking URL** below—not directly to Etsy—so the guide can help the buyer before its existing Etsy CTA.
- Pin title ≤100 characters; first sentence of the description carries the search phrase naturally. Add the 3–5 supplied topic tags only if the platform allows them.
- After publishing, record the Pin URL, board, date, outbound clicks, saves, and 30-day attributed Etsy orders (only from Etsy’s first-party stats where available).
